# Parlor · 朋友的自由桌面

拿出一副牌，掷个骰子，铺张棋盘，和朋友消磨一小会儿。Parlor 是可以共同布置的 2D 桌游空间：提供资源、容器、私有手牌和同步，玩法由同桌的人决定。

## 这一版能做什么

- **资源库**：搜索、分类、收藏，提供匹配数量、清空搜索和套装「查看单件」。缩略图在打开资源库后按可见范围绘制，切换分类保留已绘制的图。点击取用或直接拖上桌，连续取用按顺序完成并显示等待数量。扑克、UNO、月面哨站可以同时放在桌上，也能重复拿出同一副牌。
- **自由牌堆**：牌或整叠牌拖到另一张公共牌或牌堆上，自动叠到顶部；保留原正反面、内部顺序及每张牌的牌背。洗牌只打乱顺序，正面朝上的牌也会洗出来。可横向、纵向或网格展开；收回散牌也保留正反面与角度。
- **整组拖动**：重叠的公共牌自动形成一组，拖动任意露出的牌都会一起移动。位置、角度、正反面和层级保持不变，整组转交也只需一步。
- **桌面多选**：按住 `Shift` 点击物件加入或移出多选，也可按住 `Shift` 从空白处拖框，把完整框住的公共资源选入。松开 Shift 后拖动任一已选物件整体移动，保持间距、正反面、角度和层级，一次撤销恢复整组。框选略过手牌与锁定物件，拖空白处仍可移动镜头。
- **批量整理**：操作条按所选资源变化。混合物件可一起收回资源库、锁定或解锁；纯卡牌（含牌盒）可合叠、洗牌、横向/纵向/网格展开与统一翻面；棋子和筹码可合叠、展开。洗牌保留每张牌的正反面、角度与牌背。收回会保留编辑过的物件和选中的卡牌为共享资源模板，已有同款不重复保存，整批可一次撤销；锁定物件或非空袋子需先处理。
- **自由私人区**：手牌可在自己的区域随意摆放和旋转，也能原地「展示手牌」或「收回展示」。展示时同桌可见正面，移动、整理与完整存档会保留此状态；转交给别人时自动收回展示。点朋友的牌可请求交付。
- **桌上小物**：D6、D20、计分器、便签、黑白棋子、筹码、金币、方格棋盘和桌垫。可以复制、锁定位置、编辑和收起。
- **筹码堆**：筹码拖到筹码上叠放，整叠可以一起移动、展开、装袋，或取出最上面一枚。每枚保留原颜色和数值，混合面额也可叠放，由玩家自行分发与结算。
- **回合与聊天**：房主和当前回合者都能转交行动标记，当前玩家可直接点「结束回合」。按 `C` 打开可拖动的小聊天框，完整聊天记录从框内时钟按钮查看。
- **收纳袋**：把牌、卡组或小物件拖进去，再随机摸出一个。袋内不向客户端提供内容清单；摸出的牌进入自己的私有手牌。
- **共同收藏**：桌上物件和牌盒可以保存为本桌模板，重复取用。模板与实例互不影响，创建者或房主可以移除模板。
- **自由空间**：主桌与游戏桌垫的面积扩大到此前约 2.25 倍，镜头可以离开主桌，铺出其他游戏区域。小地图、全景和桌垫导航方便找回自己的位置。棋盘只拖边框或标题移动，内部空白处可移动镜头与框选棋子；选中后可聚焦整个棋盘或整组物件，并避开侧栏与手牌抽屉。
- **拖放反馈**：松手时资源留在落点，确认后直接接上同步状态；其他玩家也能看到放下的预览。网络较慢时可继续拖动其他资源，失败才退回最后确认的位置。
- **同桌动态**：操作和聊天在顶部短暂浮现，洗牌带简单动画；侧栏历史支持按玩家、类别和关键词筛选。点击昵称即可修改，聊天和改名不占桌面撤销记录。
- **下次接着玩**：房主自动存档保留原牌序、每张牌的正反面、手牌和席位；浏览器断线时保留最后确认的桌面。也可以保存完整对局或导出 JSON，隔天恢复原席位。
- **德州资源**：52 张扑克、桌垫、庄家钮、1/5/25/100/500 面值的筹码和可编辑规则指引牌。所有人自由发牌、发放和移动筹码，玩法由同桌的人约定。
- **棋类套装**：资源库「套装」提供国际象棋、象棋、斗兽棋与飞行棋。一次取出棋盘、已摆好的双方/四色棋子和可编辑指引，飞行棋另带六面骰；「查看单件」可补充单枚棋子、棋盘或指引。点击取用棋盘或整套时寻找空处并进入合适视野，拖出时按玩家指定位置摆放。棋子自由移动、复制和装袋，由玩家自行走子、吃子、交接回合与判断胜负。
- **飞行棋盘面**：按参考盘面绘制连续的 52 格色块环路、斜角转弯、四条跨越 12 格的飞行虚线和中央四色终点。四角停机坪依次为左上黄、右上绿、左下红、右下蓝。新取套装的飞机对齐停机位，已在桌上的棋子保留原位置。

2–8 人通过房主生成的链接加入，无需注册。启动成功后，终端会同时显示「房间加入链接（发给朋友）」和「房主链接（仅自己使用）」，自动打开浏览器后也能找回房主链接。Node 房主保存完整状态，浏览器只收到自己有权看到的牌面。静态试玩和联机房间共用同一个桌面引擎。

## 界面与迭代约定

桌面优先显示牌与物件，控件只保留名称、必要数量和当前状态。资源库和小地图默认收起；常用动作出现在选中操作条，其他动作放入「更多」。操作说明放在帮助、悬停提示和需要确认的操作中，不把开发说明、功能介绍或教学段落放在主界面上。新便签为空白，用户自己填写。

每轮独立改动完成相关检查后自动提交 Git，并在迭代记录中说明验证范围。提交失败时保留改动与分轮补丁，明确记录失败原因，不把暂存或构建当作已提交。

## 怎么操作

| 想做的事 | 操作 |
| --- | --- |
| 拿资源上桌 | 左侧资源按钮 / `B`，轻点添加；鼠标可拖出预览，触屏可上下滚动资源库 |
| 选择牌盒或物件 | 轻点，操作会出现在底部 |
| 移动牌盒 | 直接拖动，整副牌一起走 |
| 从牌盒抽一张 | 双击，或选中后点击「抽一张」 |
| 给朋友一张牌 | 把牌盒拖进朋友的手牌区，或使用「更多 → 转交」 |
| 移动重叠卡组 | 直接拖动任意露出的牌 |
| 多选与批量移动（桌面端） | 按住 `Shift` 点选增减，或按住 `Shift` 从空白处框选；松开键后拖动任一已选物件，点空白处或 `Esc` 取消 |
| 多选后收回资源库 | 操作条点「收回资源库」，保留选中的卡牌及修改过的物件为本桌资源，可重新取用；房主一次撤销恢复整批 |
| 只整理选中的牌 | 多选卡牌/牌盒后点「合成一叠」「洗牌」或「横向展开」；「更多」可统一正反面、纵向或网格展开 |
| 批量整理棋子 / 筹码 | 多选后「合成一叠」「展开」；「更多」可换展开方式或统一锁定、解锁 |
| 移动棋盘 / 整理盘内棋子 | 拖棋盘边框或标题移动棋盘；盘内空白处可拖镜头，也可按住 `Shift` 拖框选棋子 |
| 放回牌堆 / 合并两叠 | 拖到目标牌堆或公共牌上，出现「叠到顶部」后松手，原正反面保持 |
| 从卡组取单牌 | 选中后「抽一张」，或「横向展开」再拿；「更多」还有纵向和网格展开 |
| 翻公共单牌 | 双击，或选中后翻面 |
| 在手牌区亮牌 / 收回展示 | 双击自己的手牌，或选中后点「展示手牌 / 收回展示」；牌保留在原位置 |
| 筹码叠放 / 取单枚 | 拖到另一枚筹码上；拖动整叠，选中后可「取出一枚」或「展开」 |
| 转交回合 | 房主或当前回合者点顶部「下一位 / 结束回合」，也可在工具中选择接手玩家 |
| 旋转单牌 | `Q` / `E`，拖动时也可滚轮或按住 `Option` 左右移动 |
| 背面盖放 / 从牌堆取牌 | 手牌拖出时按住 `Shift`；牌堆「取到桌上」保持顶牌原正反面 |
| 看自己的手牌 | 底部手牌按钮 / `I`；手机横滑浏览、纵向拖出出牌，鼠标可直接拖出 |
| 摆放私人区 / 向朋友选牌 | 手牌抽屉「到私人区」，拖牌自由摆放；轻点朋友的牌背，连续选多张，等待对方交付 |
| 装入袋子 | 牌、卡组或小物拖到袋子上；双击袋子随机摸一个 |
| 编辑便签 / 掷骰 | 双击对应物件 |
| 复制 / 锁定 / 保存资源 | 选中后的「更多」；`Ctrl/⌘ D` 复制 |
| 放大卡牌 | 选中后按空格，或「更多 → 放大看看」 |
| 移动镜头 | 拖空白处；手机双指移动和缩放，鼠标滚动或右下按钮缩放 |
| 全景 / 回主桌 | `F` 看全部物件；右下按钮打开小地图，或使用「世界 → 主桌」 |
| 聚焦棋盘 / 聚焦所选 | 选中棋盘或一组物件后点「聚焦棋盘 / 聚焦所选」，也可按 `Shift + F`；桌面导航点击棋盘能完整取景 |
| 键盘浏览桌面物件 | `Tab` / `Shift + Tab` 切换焦点；屏幕外的物件自动进入视野，保留当前缩放，大棋盘必要时缩小以完整显示 |
| 聊天 / 标记位置 | `C` 开关轻量聊天框，拖动框头换位置；`P` 或双击空白处发出一次涟漪标记 |
| 德州资源 | 资源库搜索「德州」，自行取用扑克、桌垫、筹码和规则指引 |
| 飞行棋、国际象棋、斗兽棋、象棋 | 资源库「套装」一次摆好并寻找空位；「查看单件」补棋子或单拿棋盘，拖出资源可自行指定位置 |
| 存档 / 撤销 / 历史 | `Ctrl/⌘ S` 打开存档；房主点左侧撤销或按 `U`；侧栏「历史」或 `L` 开关记录 |
| 帮助 / 沉浸 | `?` / `H` |

「工具」里保留了共享骰子、回合计数、行动玩家、批量发牌和席位管理。房主可整理或回收公共牌、重置卡牌及计数、撤销最近 20 次桌面操作。每人仍在手里的牌不会因普通回收散牌而消失。

桌垫只是可自由放置的区域，不会替玩家自动执行棋类或牌类规则。锁定会防止拖动、移除以及改变卡组位置的操作；骰子和计数器仍可使用。

锁定资源在悬停或键盘聚焦时显示淡灰色锁头，选中后可在「更多」解锁。锁定位置的牌堆仍可抽牌、洗牌和接收卡牌。

旧版本的德州完整存档可直接恢复：牌、私人区和牌序保留，专用牌堆与桌垫解除程序锁定；筹码余额与已下注额转成普通筹码标记，并在历史中保留原数额。桌面物件已满时，数额仍完整记录在历史中，可腾出位置后自行取用筹码。

## 先单机试玩

macOS 双击根目录的 `试玩.command`，选择牌盒即可进入，不启动 Node 或隧道。也可以启动本地服务：

```bash
npm run dev
```

打开服务网址后点击「开始试玩」，或添加以下参数：

```text
?preview=1&pack=standard-54
?preview=1&pack=uno
?preview=1&pack=moon-outpost
```

试玩默认有房主和客人两个视角，导入多人对局后也可切换其他席位；这些身份都在当前页面内模拟。复制试玩链接不会让两个人进入同一个房间。试玩会自动保存到当前浏览器，刷新或下次选择同一牌盒时继续上次的桌面，包括原牌序、私牌位置、镜头和筹码摆放。切到后台会立即尝试保存；保存失败会显示重试入口，未保存的改动关闭页面时会提醒。

同时打开同一试玩的多个标签页时，保存冲突会自动另存为独立副本，原桌面不被覆盖；可在存档面板的「其他试玩」切换。需要重新开始时点「新开试玩」，当前完整对局会先保存为「新开前」备份。清除浏览器数据会移除自动保存，重要牌局仍可导出文件。

## 让朋友加入

要求 Node.js 18.18 或更高版本。macOS 双击 `开房.command`，填写名字并选择起始牌盒，等待终端给出邀请链接。

也可以逐行运行：

```bash
npm run setup:tunnel
npm run room -- --name "房主A" --pack ./game-packs/standard-54.json
```

`setup:tunnel` 只需首次准备。终端会校验 JSON 和图片、启动房主与 Cloudflare Quick Tunnel，健康检查通过后同时打印 HTTPS 房间加入链接和房主链接。把**房间加入链接**发给朋友，保留带 `host` 参数的房主链接自己使用；即使自动打开了浏览器，终端也会保留两条链接。房间存活期间保持终端开启。

本机双端检查可运行 `npm run dev`，使用终端给出的房主链接入座，再在「工具 → 玩家与席位」打开客人测试页。恢复凭据按浏览器标签页隔离。

## 资源与存档

内置资源：

- [标准扑克](./game-packs/standard-54.json)：完整 54 张，含大小王。
- [德州扑克](./game-packs/holdem-52.json)：52 张，不含大小王，可和任何其他卡牌自由混合成叠。
- [UNO](./game-packs/uno.json)：经典 108 张结构，数字与图形符号渲染，不含规则脚本。
- [月面哨站](./game-packs/moon-outpost.json)：8 张主题牌与 3 枚标记。
- [验收牌](./game-packs/parlor-eight.json)：8 张最小固定样本，用于隐私检查。

浏览器「导入牌盒」支持不引用本机图片的声明式 JSON，导入后保存在当前浏览器。每次导入独立保存，同 ID 的内置牌盒和其他导入仍可使用；预览左上角可移除本机导入，已拿上桌的实例会保留。使用自定义图片时，从命令行加载原始 JSON 及其同目录资源；支持 PNG、JPEG、WebP、AVIF，详见 [游戏包格式](./docs/GAME_PACK.md)。资源包不执行代码。

存档面板默认保存**完整对局**：保留席位、私人区位置与手牌、牌堆顺序、袋中物件、计数、本桌模板、聊天、操作历史与每张牌的正反面。完整文件包含所有私有牌面和个人续局口令，仅供房主保管。恢复前会先备份当前桌面；恢复保留当前房主和匹配的客人身份，清空撤销链，并保留审计记录。也可以选择**布置模板**：将手牌收回并重新洗牌，用于重新开局，不含席位。

房主服务将每次确认的操作自动保存到 `.parlor/rooms/<房间码>.room.json`，同时保留上一份 `.bak`。文件仅当前系统用户可读写，目录已排除 Git。隔天运行 `npm run room -- --resume-latest`，或在「开房.command」选择 0；指定某份续局文件可用 `--resume <路径>`。自定义图片仍需保留原资源目录，并通过 `--pack` 显式加载。

玩家可在存档面板复制自己的续局链接。房主重开后公网隧道地址可能变化：打开新的邀请链接，再粘贴原个人链接或口令即可回到原席位。浏览器会记住本机席位；若同一设备留有多个身份，会先提供选择。断线时最后确认的桌面保持可见，暂停修改并自动重试；未收到确认的操作使用相同编号重发，服务端保存回执以防重复执行。

本机存档与续局信息使用 IndexedDB；收藏星标使用本机存储，当前标签页的身份使用 sessionStorage。清除浏览器数据会移除本机信息，文件导出适合备份或换设备。房主服务仍需运行才可继续同步。

图片不会嵌入存档。带图片的桌面恢复到其他房间时，需要房主同时加载对应原始资源包；缺失图片时仍能使用文字和牌背兜底。本桌模板会随完整对局和自动存档一起保留；浏览器的收藏星标只保留在本机。

每桌上限为 32 副牌、1500 张卡牌、240 个物件与标记、40 个本桌模板。可放置区域约 10800 × 7100 世界单位，主桌只是其中一个起点。

## 可选静态部署

默认 Quick Tunnel 已同时提供网页和 API，不要求 Vercel。如果希望有固定前端网址：

```bash
npm run build
PUBLIC_APP_URL="https://你的前端域名" npm run room -- --name "房主A"
```

`dist/` 可静态托管，仓库包含 `vercel.json`。入口页的脚本和样式链接按文件内容生成版本号，更新部署后刷新会请求对应的新资源。Node 房间服务也使用相同的资源版本，并要求入口、脚本和样式重新校验缓存。

HTTPS 或本机地址首次成功打开后，支持 Service Worker 的浏览器会缓存完整的公开客户端。房主服务暂时离线时，刷新仍能显示本机最后确认的桌面与镜头，恢复连接后继续原席位。缓存不包含房间 API、事件流、私牌图片或带身份口令的 URL；完整多人状态仍由房主保存，房主在线时才能同步新操作。离线入口更新会校验整套内容，下载不完整或存储失败时保留上一套可用文件；联网导航优先读取最新页面。`file://` 试玩继续可用，但不注册离线入口缓存。
