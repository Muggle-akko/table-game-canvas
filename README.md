# Parlor · 朋友的自由桌面

拿出一副牌，掷个骰子，铺张棋盘，和朋友消磨一小会儿。Parlor 是可以共同布置的 2D 桌游空间：提供资源、容器、私有手牌和同步，玩法由同桌的人决定。

## 这一版能做什么

- **资源库**：搜索、分类、收藏，点击取用或直接拖上桌，连续取用按顺序完成并显示等待数量。扑克、UNO、月面哨站可以同时放在桌上，也能重复拿出同一副牌。
- **独立牌盒**：各自保留牌背、位置、剩余数量和来源。洗牌、抽牌、发牌针对选中的牌盒；收回散牌时回到原来的牌盒。
- **整组拖动**：重叠的公共牌自动形成一组，拖动任意露出的牌都会一起移动。位置、角度、正反面和层级保持不变，整组转交也只需一步。
- **自由私人区**：私有牌可在自己的区域随意摆放和旋转。点朋友的牌背可连续标记多张，颜色跟随指针，8 秒消失；朋友点击交付后，牌才进入你的私人区。
- **桌上小物**：D6、D20、计分器、便签、黑白棋子、筹码、金币、方格棋盘和桌垫。可以复制、锁定位置、编辑和收起。
- **收纳袋**：把牌、卡组或小物件拖进去，再随机摸出一个。袋内不向客户端提供内容清单；摸出的牌进入自己的私有手牌。
- **共同收藏**：桌上物件和牌盒可以保存为本桌模板，重复取用。模板与实例互不影响，创建者或房主可以移除模板。
- **自由空间**：镜头可以离开主桌，铺出其他游戏区域。小地图、全景和桌垫导航方便找回自己的位置。
- **同桌动态**：操作和聊天在顶部短暂浮现，洗牌带简单动画；侧栏历史支持按玩家、类别和关键词筛选。点击昵称即可修改，聊天和改名不占桌面撤销记录。
- **下次接着玩**：房主自动存档保留原牌序、手牌、席位和下注进度；浏览器断线时保留最后确认的桌面。也可以保存完整对局或导出 JSON，隔天恢复原席位。
- **德州扑克**：独立的 52 张牌、庄家和盲注、无限注行动、主池和边池、摊牌结算；可以休息、补充虚拟筹码，房主可撤销操作。

2–8 人通过房主生成的链接加入，无需注册。启动成功后，终端会同时显示「房间加入链接（发给朋友）」和「房主链接（仅自己使用）」，自动打开浏览器后也能找回房主链接。Node 房主保存完整状态，浏览器只收到自己有权看到的牌面。静态试玩和联机房间共用同一个规则引擎。

## 界面与迭代约定

桌面优先显示牌与物件，控件只保留名称、必要数量和当前状态。资源库和小地图默认收起；常用动作出现在选中操作条，其他动作放入「更多」。操作说明放在帮助、悬停提示和需要确认的操作中，不把开发说明、功能介绍或教学段落放在主界面上。新便签为空白，用户自己填写。

每轮独立改动完成相关检查后自动提交 Git，并在迭代记录中说明验证范围。提交失败时保留改动与分轮补丁，明确记录失败原因，不把暂存或构建当作已提交。

## 怎么操作

| 想做的事 | 操作 |
| --- | --- |
| 拿资源上桌 | 左侧资源按钮 / `B`，轻点添加；鼠标可拖出预览，触屏可上下滚动资源库 |
| 选择牌盒或物件 | 轻点，操作会出现在底部 |
| 移动牌盒 | 直接拖动，整副牌一起走 |
| 从牌盒抽一张 | 双击，或选中后点击「抽一张」 |
| 给朋友一张牌 | 把牌盒拖进朋友的手牌区，或使用「更多 → 转交」 |
| 移动重叠卡组 | 直接拖动任意露出的牌 |
| 从卡组取单牌 | 选中后「抽一张」，或「展开」再拿 |
| 翻公共单牌 | 双击，或选中后翻面 |
| 旋转单牌 | `Q` / `E`，拖动时也可滚轮或按住 `Option` 左右移动 |
| 背面盖放 | 手牌拖出时按住 `Shift`；牌盒操作条也有「盖放」 |
| 看自己的手牌 | 底部手牌按钮 / `I`；手机横滑浏览、纵向拖出出牌，鼠标可直接拖出 |
| 摆放私人区 / 向朋友选牌 | 手牌抽屉「到私人区」，拖牌自由摆放；轻点朋友的牌背，连续选多张，等待对方交付 |
| 装入袋子 | 牌、卡组或小物拖到袋子上；双击袋子随机摸一个 |
| 编辑便签 / 掷骰 | 双击对应物件 |
| 复制 / 锁定 / 保存资源 | 选中后的「更多」；`Ctrl/⌘ D` 复制 |
| 放大卡牌 | 选中后按空格，或「更多 → 放大看看」 |
| 移动镜头 | 拖空白处；手机双指移动和缩放，鼠标滚动或右下按钮缩放 |
| 全景 / 回主桌 | `F` 看全部物件；右下按钮打开小地图，或使用「世界 → 主桌」 |
| 聊天 / 标记位置 | `C` / `P`，也可双击桌面空白处标记 |
| 德州助手 | 侧栏「德州」 / `T`，房主铺桌后发牌开局 |
| 存档 / 撤销 / 历史 | `Ctrl/⌘ S` 打开存档；房主点左侧撤销或按 `U`；侧栏「历史」或 `L` 开关记录 |
| 帮助 / 沉浸 | `?` / `H` |

「工具」里保留了共享骰子、回合计数、行动玩家、批量发牌和席位管理。房主可整理或回收公共牌、重置卡牌及计数、撤销最近 20 次桌面操作。每人仍在手里的牌不会因普通回收散牌而消失。

桌垫只是可自由放置的区域，不会替玩家自动执行棋类或牌类规则。锁定会防止拖动、移除以及改变卡组位置的操作；骰子和计数器仍可使用。

点击侧栏「德州」或按 `T` 可开启德州助手。房主选择参加的 2–8 人、初始筹码与大小盲后，助手添加独立的 52 张牌和桌垫。玩家在自己的回合过牌、跟注、加注到本轮总额、全下或弃牌；每轮结束由房主发下一轮公共牌，河牌后摊牌并自动分配主池和边池。手机面板同时显示自己的底牌和公共牌，底牌仍可在私人区整理。

德州采用无限注、整数虚拟筹码：处理不足额全下的加注权、退回未被跟注部分、七选五牌型与平分零头（从庄家左侧顺时针）。不设置行动倒计时；下一手保留筹码、轮换庄家，可补充筹码或选择下手休息。完整对局和房主自动存档保留下注阶段、筹码和行动顺序。德州进行中不能手动抽走、复制或转交专用牌，结束助手后牌盒与桌垫恢复自由操作。

只剩一人有筹码时，只需匹配对手实际全下的金额；已匹配则直接等待发公共牌。无人跟注的胜利不强制亮底牌，玩家可在结束后自愿亮牌。确实离线的当前行动玩家可由房主代为弃牌，历史会注明房主操作；过期的下注、关闭助手和撤销前仍在途的未知操作会拒绝执行。

## 先单机试玩

macOS 双击根目录的 `试玩.command`，选择牌盒即可进入，不启动 Node 或隧道。也可以启动本地服务：

```bash
npm run dev
```

打开服务网址后点击「开始试玩」，或添加以下参数：

```text
?preview=1&pack=standard-54
?preview=1&pack=uno
?preview=1&pack=moon-outpost
```

试玩默认有房主和客人两个视角，导入多人对局后也可切换其他席位；这些身份都在当前页面内模拟。复制试玩链接不会让两个人进入同一个房间。试玩会自动保存到当前浏览器，刷新或下次选择同一牌盒时继续上次的桌面，包括原牌序、私牌位置、镜头和德州进度。切到后台会立即尝试保存；保存失败会显示重试入口，未保存的改动关闭页面时会提醒。

同时打开同一试玩的多个标签页时，保存冲突会自动另存为独立副本，原桌面不被覆盖；可在存档面板的「其他试玩」切换。需要重新开始时点「新开试玩」，当前完整对局会先保存为「新开前」备份。清除浏览器数据会移除自动保存，重要牌局仍可导出文件。

## 让朋友加入

要求 Node.js 18.18 或更高版本。macOS 双击 `开房.command`，填写名字并选择起始牌盒，等待终端给出邀请链接。

也可以逐行运行：

```bash
npm run setup:tunnel
npm run room -- --name "房主A" --pack ./game-packs/standard-54.json
```

`setup:tunnel` 只需首次准备。终端会校验 JSON 和图片、启动房主与 Cloudflare Quick Tunnel，健康检查通过后同时打印 HTTPS 房间加入链接和房主链接。把**房间加入链接**发给朋友，保留带 `host` 参数的房主链接自己使用；即使自动打开了浏览器，终端也会保留两条链接。房间存活期间保持终端开启。

本机双端检查可运行 `npm run dev`，使用终端给出的房主链接入座，再在「工具 → 玩家与席位」打开客人测试页。恢复凭据按浏览器标签页隔离。

## 资源与存档

内置资源：

- [标准扑克](./game-packs/standard-54.json)：完整 54 张，含大小王。
- [德州扑克](./game-packs/holdem-52.json)：52 张，不含大小王；可自由取用，德州助手另建独立牌盒。
- [UNO](./game-packs/uno.json)：经典 108 张结构，数字与图形符号渲染，不含规则脚本。
- [月面哨站](./game-packs/moon-outpost.json)：8 张主题牌与 3 枚标记。
- [验收牌](./game-packs/parlor-eight.json)：8 张最小固定样本，用于隐私检查。

浏览器「导入牌盒」支持不引用本机图片的声明式 JSON，导入后保存在当前浏览器。每次导入独立保存，同 ID 的内置牌盒和其他导入仍可使用；预览左上角可移除本机导入，已拿上桌的实例会保留。使用自定义图片时，从命令行加载原始 JSON 及其同目录资源；支持 PNG、JPEG、WebP、AVIF，详见 [游戏包格式](./docs/GAME_PACK.md)。资源包不执行代码。

存档面板默认保存**完整对局**：保留席位、私人区位置与手牌、牌堆顺序、袋中物件、计数、本桌模板、聊天、操作历史与德州进度。完整文件包含所有私有牌面和个人续局口令，仅供房主保管。恢复前会先备份当前桌面；恢复保留当前房主和匹配的客人身份，清空撤销链，并保留审计记录。也可以选择**布置模板**：将手牌收回并重新洗牌，用于重新开局，不含席位或德州规则进度。

房主服务将每次确认的操作自动保存到 `.parlor/rooms/<房间码>.room.json`，同时保留上一份 `.bak`。文件仅当前系统用户可读写，目录已排除 Git。隔天运行 `npm run room -- --resume-latest`，或在「开房.command」选择 0；指定某份续局文件可用 `--resume <路径>`。自定义图片仍需保留原资源目录，并通过 `--pack` 显式加载。

玩家可在存档面板复制自己的续局链接。房主重开后公网隧道地址可能变化：打开新的邀请链接，再粘贴原个人链接或口令即可回到原席位。浏览器会记住本机席位；若同一设备留有多个身份，会先提供选择。断线时最后确认的桌面保持可见，暂停修改并自动重试；未收到确认的操作使用相同编号重发，服务端保存回执以防重复执行。

本机存档与续局信息使用 IndexedDB；收藏星标使用本机存储，当前标签页的身份使用 sessionStorage。清除浏览器数据会移除本机信息，文件导出适合备份或换设备。房主服务仍需运行才可继续同步。

图片不会嵌入存档。带图片的桌面恢复到其他房间时，需要房主同时加载对应原始资源包；缺失图片时仍能使用文字和牌背兜底。本桌模板会随完整对局和自动存档一起保留；浏览器的收藏星标只保留在本机。

每桌上限为 32 副牌、1500 张卡牌、240 个物件与标记、40 个本桌模板。可放置区域约 10800 × 7100 世界单位，主桌只是其中一个起点。

## 可选静态部署

默认 Quick Tunnel 已同时提供网页和 API，不要求 Vercel。如果希望有固定前端网址：

```bash
npm run build
PUBLIC_APP_URL="https://你的前端域名" npm run room -- --name "房主A"
```

`dist/` 可静态托管，仓库包含 `vercel.json`。入口页的脚本和样式链接按文件内容生成版本号，更新部署后刷新会请求对应的新资源。Node 房间服务也使用相同的资源版本，并要求入口、脚本和样式重新校验缓存。固定前端不保存房间状态；房主仍需在线。
