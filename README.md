# Parlor · 朋友的自由桌面

拿出一副牌，掷个骰子，铺张棋盘，和朋友消磨一小会儿。Parlor 是可以共同布置的 2D 桌游空间：提供资源、容器、私有手牌和同步，玩法由同桌的人决定。

## 这一版能做什么

- **资源库**：搜索、分类、收藏，点击取用或直接拖上桌。扑克、UNO、月面哨站可以同时放在桌上，也能重复拿出同一副牌。
- **独立牌盒**：各自保留牌背、位置、剩余数量和来源。洗牌、抽牌、发牌针对选中的牌盒；收回散牌时回到原来的牌盒。
- **整组拖动**：重叠的公共牌自动形成一组，拖动任意露出的牌都会一起移动。位置、角度、正反面和层级保持不变，整组转交也只需一步。
- **桌上小物**：D6、D20、计分器、便签、黑白棋子、筹码、金币、方格棋盘和桌垫。可以复制、锁定位置、编辑和收起。
- **收纳袋**：把牌、卡组或小物件拖进去，再随机摸出一个。袋内不向客户端提供内容清单；摸出的牌进入自己的私有手牌。
- **共同收藏**：桌上物件和牌盒可以保存为本桌模板，重复取用。模板与实例互不影响，创建者或房主可以移除模板。
- **自由空间**：镜头可以离开主桌，铺出其他游戏区域。小地图、全景和桌垫导航方便找回自己的位置。
- **随手聊聊**：房间内文字聊天、桌边状态、玩家定位和注意力标记。聊天和状态不占桌面撤销记录。
- **下次接着玩**：房主可将桌面存到这个浏览器，或导出 JSON 文件。恢复布置保留当前玩家与连接，且可以撤销。

2–8 人通过房主生成的链接加入，无需注册。Node 房主保存完整状态，浏览器只收到自己有权看到的牌面。静态试玩和联机房间共用同一个规则引擎。

## 界面与迭代约定

桌面优先显示牌与物件，控件只保留名称、必要数量和当前状态。资源库和小地图默认收起；常用动作出现在选中操作条，其他动作放入「更多」。操作说明放在帮助、悬停提示和需要确认的操作中，不把开发说明、功能介绍或教学段落放在主界面上。新便签为空白，用户自己填写。

每轮独立改动完成相关检查后自动提交 Git，并在迭代记录中说明验证范围。提交失败时保留改动与分轮补丁，明确记录失败原因，不把暂存或构建当作已提交。

## 怎么操作

| 想做的事 | 操作 |
| --- | --- |
| 拿资源上桌 | 左侧资源按钮 / `B`，轻点添加；鼠标可拖出预览，触屏可上下滚动资源库 |
| 选择牌盒或物件 | 轻点，操作会出现在底部 |
| 移动牌盒 | 直接拖动，整副牌一起走 |
| 从牌盒抽一张 | 双击，或选中后点击「抽一张」 |
| 给朋友一张牌 | 把牌盒拖进朋友的手牌区，或使用「更多 → 转交」 |
| 移动重叠卡组 | 直接拖动任意露出的牌 |
| 从卡组取单牌 | 选中后「抽一张」，或「展开」再拿 |
| 翻公共单牌 | 双击，或选中后翻面 |
| 旋转单牌 | `Q` / `E`，拖动时也可滚轮或按住 `Option` 左右移动 |
| 背面盖放 | 手牌拖出时按住 `Shift`；牌盒操作条也有「盖放」 |
| 看自己的手牌 | 底部手牌按钮 / `I`；手机横滑浏览、纵向拖出出牌，鼠标可直接拖出 |
| 装入袋子 | 牌、卡组或小物拖到袋子上；双击袋子随机摸一个 |
| 编辑便签 / 掷骰 | 双击对应物件 |
| 复制 / 锁定 / 保存资源 | 选中后的「更多」；`Ctrl/⌘ D` 复制 |
| 放大卡牌 | 选中后按空格，或「更多 → 放大看看」 |
| 移动镜头 | 拖空白处；手机双指移动和缩放，鼠标滚动或右下按钮缩放 |
| 全景 / 回主桌 | `F` 看全部物件；右下按钮打开小地图，或使用「世界 → 主桌」 |
| 聊天 / 标记位置 | `C` / `P`，也可双击桌面空白处标记 |
| 存档 / 撤销 | `Ctrl/⌘ S` 打开存档；房主点左侧撤销或按 `U`；「工具 → 历史」查看记录 |
| 帮助 / 沉浸 | `?` / `H` |

「工具」里保留了共享骰子、回合计数、行动玩家、批量发牌和席位管理。房主可整理或回收公共牌、重置卡牌及计数、撤销最近 20 次桌面操作。每人仍在手里的牌不会因普通回收散牌而消失。

桌垫只是可自由放置的区域，不会替玩家自动执行棋类或牌类规则。锁定会防止拖动、移除以及改变卡组位置的操作；骰子和计数器仍可使用。

## 先单机试玩

macOS 双击根目录的 `试玩.command`，选择牌盒即可进入，不启动 Node 或隧道。也可以启动本地服务：

```bash
npm run dev
```

打开服务网址后点击「开始试玩」，或添加以下参数：

```text
?preview=1&pack=standard-54
?preview=1&pack=uno
?preview=1&pack=moon-outpost
```

试玩可以切换房主和客人视角。同一个浏览器页面内模拟两种身份；复制试玩链接不会让两个人进入同一个房间。试玩的桌面在刷新时重建，喜欢的布置请保存或导出。

## 让朋友加入

要求 Node.js 18.18 或更高版本。macOS 双击 `开房.command`，填写名字并选择起始牌盒，等待终端给出邀请链接。

也可以逐行运行：

```bash
npm run setup:tunnel
npm run room -- --name "房主A" --pack ./game-packs/standard-54.json
```

`setup:tunnel` 只需首次准备。终端会校验 JSON 和图片、启动房主与 Cloudflare Quick Tunnel，健康检查通过后才打印 HTTPS 邀请链接。把**访客链接**发给朋友，保留带 `host` 参数的房主链接自己使用。房间存活期间保持终端开启。

本机双端检查可运行 `npm run dev`，使用终端给出的房主链接入座，再在「工具 → 玩家与席位」打开客人测试页。恢复凭据按浏览器标签页隔离。

## 资源与存档

内置资源：

- [标准扑克](./game-packs/standard-54.json)：完整 54 张，含大小王。
- [UNO](./game-packs/uno.json)：经典 108 张结构，文字与颜色渲染，不含规则脚本。
- [月面哨站](./game-packs/moon-outpost.json)：8 张主题牌与 3 枚标记。
- [验收牌](./game-packs/parlor-eight.json)：8 张最小固定样本，用于隐私检查。

浏览器「导入牌盒」支持不引用本机图片的声明式 JSON，导入后保存在当前浏览器。每次导入独立保存，同 ID 的内置牌盒和其他导入仍可使用；预览左上角可移除本机导入，已拿上桌的实例会保留。使用自定义图片时，从命令行加载原始 JSON 及其同目录资源；支持 PNG、JPEG、WebP、AVIF，详见 [游戏包格式](./docs/GAME_PACK.md)。资源包不执行代码。

本机桌面存档使用 IndexedDB，收藏星标使用本机存储；清除浏览器数据会移除它们。文件导出更适合备份或换设备。文件包含布置、资源和计数；私有手牌在保存的副本中归回各自牌盒，不保存玩家身份、会话或聊天。恢复时隐藏牌重新编号并洗牌，不复现玩家的私有手牌。

图片不会嵌入存档。带图片的桌面恢复到其他房间时，需要房主同时加载对应原始资源包；缺失图片时仍能使用文字和牌背兜底。本桌模板只在当前房间有效，房主进程停止后请通过桌面存档保留想带走的实例。

每桌上限为 32 副牌、1500 张卡牌、240 个物件与标记、40 个本桌模板。可放置区域约 10800 × 7100 世界单位，主桌只是其中一个起点。

## 可选静态部署

默认 Quick Tunnel 已同时提供网页和 API，不要求 Vercel。如果希望有固定前端网址：

```bash
npm run build
PUBLIC_APP_URL="https://你的前端域名" npm run room -- --name "房主A"
```

`dist/` 可静态托管，仓库包含 `vercel.json`。固定前端不保存房间状态；房主仍需在线。

## 代码与验证

- `src/room-engine.mjs`：权威状态、权限、资源、容器、模板、存档、撤销。
- `scripts/build-client.mjs`：从同一源文件生成浏览器引擎和内置资源目录。
- `public/preview-engine.js`：单机适配，不再维护第二套规则。
- `public/app.js`：会话、投影渲染、镜头与拖动。
- `public/workspace-ui.js`：资源库、小物件、手牌抽屉、地图、聊天和存档界面。
- `public/vault.js`：本机持久化。
- `src/room-transport.mjs`：HTTP/SSE、过滤后的命令回执、实时光标、图片鉴权。

```bash
npm run check
npm run build
```
