## 1. 入口与布局

- 打开根网址，欢迎页显示实际卡牌、骰子和便签，三个试玩牌盒都能进入。
- 进入桌面时资源库保持收起；没有常驻教学段落、底部说明栏或默认写着教学文字的便签。帮助和按钮悬停仍能找到操作说明。
- 抽牌、翻面等常用动作可以直接使用；「更多」中的旋转、转交、收回等动作仍可访问。聊天或玩家状态更新时，展开菜单、焦点和已选转交对象保持不变。
- 桌面尺寸 1440 × 900、1024 × 768 时，牌面、资源库、选择操作条、手牌抽屉和小地图不相互覆盖主要操作。
- 手机 390 × 844、320 × 740 时，没有页面横向滚动；资源库和聊天可关闭，输入时侧栏不会因键盘引发 resize 而消失。
- 所有主要控件可用键盘访问，焦点可见；Escape 关闭当前面板或取消拖动。
- 「更多」展开时，Escape 先关闭菜单并保留选择；「工具 → 历史」关闭后焦点回到可见的工具按钮。访客的撤销按钮禁用。
- 系统开启减少动态效果后，不依赖动画完成操作。

## 2. 资源库

- 分类与中英文关键词能筛选；无结果时显示明确提示。
- 扑克、UNO、月面哨站可以同时存在；重复添加同一牌盒得到独立实例，旧手牌保留。
- 点击取用与鼠标拖动取用都把实例放在可见位置；Escape、指针取消、捕获丢失、窗口失焦、关闭资源库与落到其他控件均不添加资源，也没有残留拖动预览。
- 手机从资源预览上起手可上下滚动资源库，滑动不会误添加；轻点仍能添加并收起资源库。
- 网络延迟时连续取用同一种资源，等待数量逐项消失，每次取用都产生独立实例；远端同时添加资源不影响选中结果。等待期间打开聊天或选择其他物件，完成后保持新的操作意图。
- 收藏星标刷新后保留；本桌模板可重复取用，创建者和房主可移除。
- 房主导入合法无图片 JSON 后能拿出资源，刷新后仍能在当前浏览器的资源库找到。
- 导入与内置资源相同 ID 的 JSON，以及同 ID 的两份修改版，都分别显示并可取用；旧版保存的导入仍可访问。
- 移除一份本机导入时可以取消；确认后刷新资源库仍保持删除，内置资源、其他导入和桌上实例不受影响。
- 损坏 JSON、图片引用、过大文件和无权限操作有明确提示，桌面不会部分变更。

## 3. 牌盒与卡组

- 轻点牌盒只选中；双击抽一张到自己的手牌；拖动牌盒移动整副，不凭空抽牌。
- 牌盒拖进任意玩家手牌区时只发一张，牌盒位置不变，只有接收者看到正面。
- 选中不同牌盒后抽牌、洗牌、发牌和数量上限切换到该牌盒。
- 不同来源的隐藏牌显示各自牌背；收回散牌按来源回到对应牌盒。
- 两张或多张重叠公共牌显示数量；拖动顶牌或露出的底牌都会移动整组。
- 整组移动保留相对位置、旋转、正反面和顺序；世界边缘整体限位，不挤在一起。
- 整组进手牌只产生一次操作，接收者能看所有牌面，房主一步撤销恢复整组。
- 选中卡组可抽一张、洗牌、展开；锁定成员会阻止整组操作、整理和收回，提示解锁且整次操作没有部分变更。
- 单牌可翻面、Q/E 旋转；手牌按 Shift 拖出从第一次广播起就是背面。
- 从底部手牌抽屉拖牌时，牌不会跳回远处的固定手牌区坐标。
- 手机从手牌正面起手，横向滑动可浏览，轻点可选择，纵向拖出只出一张牌；浏览器接管横滑后不会残留拖动或误选。
- 朋友发来新牌时，已有手牌、焦点、当前浏览位置和拖牌保持稳定；关闭抽屉、第二根手指落下或系统取消时不误出牌。
- Escape、pointer cancel、失去窗口焦点和落到控件上均不会提交半次拖动。

## 4. 物件与容器

- 骰子双击掷出有效点数，同桌结果一致；计分器加减与便签编辑正常。
- 便签中的 HTML 字符串按文字显示；长内容可打开编辑器完整查看。
- 复制得到独立物件；锁定后可选择并解锁；删除与编辑可由房主撤销。
- 棋盘在卡牌和棋子下面，标签可读；桌垫导航能回到对应区域。
- 单牌、卡组、筹码、骰子可装进袋子；牌盒、棋盘和袋子不能嵌套装入。
- 袋子只显示数量。其他玩家的状态、拖动幽灵和图片入口都不能读取袋内资源。
- 随机摸出卡牌进入操作者手牌；摸出小物件放在袋子附近。
- 非空袋子不能复制、删除或保存模板，防止遗漏内容；先取空后可操作。

## 5. 小世界与轻社交

- 玩家镜头互相独立，能拖到原主桌外；F 可容纳所有桌面物件。
- 手机双指移动和缩放以指间位置为中心，换指或抬起一根后镜头不跳动；缩放可以从牌面或物件上开始，不修改共享桌面。
- 双指操作结束不额外抽牌、翻牌或打开卡牌预览。取消、窗口失焦和捕获丢失后没有残留手势，下次单指拖空白可以正常移动。
- 小地图默认收起，桌面和手机均可从右下打开；沉浸模式中也能主动查看。点击、方向键移动、桌垫定位和回主桌都可用。
- 小地图 Escape 关闭后恢复按钮焦点；打开其他面板或选择物件时收起，手机打开小地图时收起手牌抽屉。镜头和面板操作不改变共享桌面状态。
- 聊天可以发送并即时出现，输入 HTML 只显示文字，空消息不会发送。
- 未打开聊天时有未读提示，打开后清除；刷新只保留当前房间最近消息。
- 桌边状态同步给朋友；聊天和状态不会挤掉桌面撤销记录。
- 注意力标记出现在相同世界坐标；玩家头像可以定位光标或手牌区。

## 6. 本机存档

- 房主保存布置后刷新页面，能从同一浏览器找到存档并恢复。
- 导出文件再导入后能恢复各牌盒、袋内物件、卡牌位置、便签和计数。
- 保存不改变正在玩的手牌；保存的副本将手牌归回来源牌盒。
- 文件不包含玩家 ID、会话、房主凭据或聊天；恢复后隐藏牌重新洗牌和编号。
- 恢复保留当前玩家和会话，客人可以继续操作；房主可撤销恢复。
- 禁用存储或模拟空间不足时显示失败，不出现已保存成功的提示。
- 带图片的存档恢复时，缺少原资源文件有文字兜底；具备同一资源包的房间能鉴权读取图片。

## 7. 本地双标签与断线

运行 `npm run dev`，使用终端给出的房主链接入座，在工具中打开客人测试页。

- 身份凭据按标签页隔离，刷新客人页不会覆盖房主身份。
- 新加入玩家只拿到允许看到的当前投影；客人无法读取其他人的私有卡面图片。
- 私有牌公开后所有人可见，收回后其他人的 DOM 与下一次 API 请求重新隐藏。
- 真实拖动中对方可见卡组、对象和对应牌盒的幽灵，消息不携带私有正面。
- SSE 暂时中断时显示恢复状态；命令回执保持正确的过滤投影，不误报已经看见新布局。
- 彻底关闭房主后，客户端显示房间不可用；重开新房间时不复用失效凭据。
- 主动离席释放名额，私有牌返回各自牌盒；清理离线席位不删除在线玩家。

## 8. 公网双人

房主 A 与客人 B 使用不同网络。执行：

```bash
npm run room -- --name "房主A" --pack ./game-packs/parlor-eight.json
```

- JSON 和图片校验发生在监听之前；端口、隧道或健康检查失败时清楚报错并收尾。
- 健康检查通过后打印 HTTPS 访客链接，链接不含房主凭据。
- B 无需安装或注册即可入座，并与 A 完成抽牌、转交、卡组拖动、装袋、掷骰、聊天和存档恢复。
- B 刷新和短暂网络波动后能恢复自己的席位及私有投影。
- A 关闭终端后，B 明确看到房间结束或不可用。
