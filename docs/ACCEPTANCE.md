## 2. 入口、布局与无障碍

- 根网址显示欢迎页，四种试玩牌盒可进入；进入桌面后资源库和小地图默认收起。主要操作没有横向溢出或被面板遮挡。
- 更新部署后普通刷新入口，脚本和样式请求带当前内容版本；无需依赖五分钟缓存到期。首次进入、平移缩放、切窗口再回来后，本机光标可见并能继续拖动、抽牌。
- 单牌、卡组、牌盒的操作随选择出现；聊天、改名或远端更新不重置「更多」菜单、转交对象、焦点和输入草稿。
- 侧栏历史 / L、聊天 / C、手牌 / I、位置标记 / P、存档 / Ctrl/⌘ S 各自工作，没有快捷键冲突；输入文字时不触发桌面快捷键。德州通过资源库取用。
- 手机面板可关闭，软键盘出现时不会丢失输入。Tab 焦点可见；Escape 依次取消拖动、关闭菜单或面板并回到可见入口。
- 开启「减少动态效果」后，所有功能可用，不依赖动画完成；UNO 用图形符号表达，读屏仍能读到中文牌名。

## 3. 资源、卡组与容器

- 搜索、分类、收藏和无结果提示有效。四类内置牌盒可同时存在，重复取用产生独立实例。
- 点击或鼠标拖出资源可添加；触屏从预览起手能滚动资源库，轻点才添加。Escape、取消、失焦、关闭面板或落到控件上不添加，预览无残留。
- 延迟时连续取用按顺序完成并递减等待数；远端同时添加资源不会让回执选错物件，后来主动选择的对象仍保留。
- 同 ID 的导入、内置包和另一份导入分别保留；删除一份本机导入不删除桌上实例。损坏、超限或带本机图片引用的浏览器导入被完整拒绝。
- 牌盒轻点选择、双击抽一张、拖动移动整副；拖进手牌区只发一张。抽牌、发牌、洗牌针对当前牌盒，来源牌背正确。
- 单牌、散牌组或整叠拖到公共牌/牌堆上，提示「叠到顶部」；松手追加到顶部，原牌面、角度和内部顺序不变。两叠可混合来源；原主牌堆合并消失后，工具仍能操作剩余牌堆。
- 洗牌只改变顺序；被盖住的正面不出现在当前投影和图片接口中，洗到顶部后正常显示。取到桌上、横向/纵向/网格展开和收回散牌均保留朝向。
- 锁定的牌、牌堆、筹码和桌垫在 hover 或键盘聚焦时显示淡灰锁头；提示不接收指针事件。位置锁定的牌堆仍可收牌、抽牌和洗牌。
- 重叠公共牌作为整组移动，保留相对位置、角度和顺序；世界边缘整体限位。整组转交可一步撤销；锁定任一成员时原子拒绝移动、洗牌、展开和收回。
- 骰子、计分器、便签、复制、锁定、编辑、模板、移除均可使用；便签中的 HTML 按文字显示。
- 牌、卡组和小物可装袋；袋内只显示数量，其他人无法从投影、图片接口或拖动事件读取内容。随机摸牌进入本人手牌。非空袋不可复制、删除或存为模板。

## 4. 私人区、触摸与远端拖动

- 私人区牌可自由移动和旋转，刷新、抽新牌、改名和新玩家加入不打乱已有摆放。「到私人区」定位正确，「整理」只整理本人的牌。
- 底部手牌抽屉鼠标拖出不跳位置；手机横滑浏览、轻点选择、纵向拖出一张。Shift 盖放从第一次广播起就不暴露正面。
- 新牌到来保持焦点和手牌浏览位置；关闭抽屉、第二根手指、系统取消、失焦和落到控件均不误出牌。
- 可连续点选朋友最多 12 张私牌，标记与请求者光标同色，8 秒消失；只有持有者能交付。请求过期、混合归属或锁定时整次交付失败，不会部分移动。
- 请求信号没有牌面、不占审计和撤销；房主也不能代替朋友接受交付。德州牌与其他资源使用相同的转交逻辑。
- 双端可见牌、卡组、牌盒和物件的拖动，遮挡与牌背正确。持续拖住仍显示，松手、断线或取消后清理；迟到坐标不复活已结束拖动。
- 记录多人拖动的消息频率、字节数和视觉延迟。当前协议测试为 10 Hz、108 张整叠牌单事件小于 500 字节；不据此推断真实网络顺滑程度。
- 双指缩放和平移以指间位置为中心，换指不跳，结束后不误抽牌或翻牌；镜头和小地图操作只影响自己。

## 5. 动态、聊天与审计

- 普通操作与聊天在顶部短暂提示，颜色对应玩家；点击分别进入历史或聊天。历史可从侧栏开关并回到原入口焦点。
- SSE 与命令回执到达顺序不同也只弹一次；入座、刷新、切换试玩视角不重放旧消息。洗牌播放一次本地动画并自动清理。
- 聊天未读提示在打开后清除；HTML 只显示文字。点击本人昵称修改后身份、颜色和手牌保留，重名自动区分。
- 历史保留最近 500 条，支持玩家、类别、关键词与筛选导出。改名前后按相同玩家 ID 检索；撤销追加关联记录，原操作不被删掉。
- 恢复对局合并审计记录并注明恢复；聊天只保留最近 60 条。导出的筛选历史不含私有牌面或续局凭据。

## 6. 完整对局、布置模板与隔天续局

- 存档默认「完整对局」，包含原牌序、每张牌的正反面与来源、私人区坐标、手牌归属、袋中资源、计数、本桌模板、席位、聊天和历史。保存不修改正在玩的桌面。
- 文件提示清楚说明完整文件含全部私有牌面与个人续局口令；客人不能导出整个对局。普通邀请链接不含房主或个人凭据。
- 完整恢复前自动保存「恢复前」副本；无效文件或备份失败不修改桌面。恢复后当前房主身份保留，匹配客人保持身份，原牌序保留但牌 ID 重新编号。
- 完整恢复和服务重启清空撤销链；普通桌面撤销不会删除审计。布置模板保留当前席位，将手牌归回并洗牌，用于重新布置。
- 文件导出后在另一浏览器导入可恢复；图片没有打包，原资源通过 `--pack` 显式加载，缺失时文字兜底。
- 禁用存储或空间不足时显示失败，不能显示保存成功；浏览器收藏与完整对局中的本桌模板区分正确。
- 每次已确认操作写入 `.parlor/rooms/<房间码>.room.json`，保留上一份 `.bak`；相同文件不能被两个房主进程同时打开。写盘失败时提示尚未保存，恢复后安全重试，不重复动作。
- 退出房主后使用 `npm run room -- --resume-latest` 或「开房.command」选 0，原牌序、手牌、坐标与筹码摆放继续。指定文件用 `--resume <路径>`。
- 新隧道地址变化时使用新邀请地址，粘贴原个人链接或口令回到同一席位；错误口令不另建身份。同一浏览器有多个已保存身份时明确选择，不默认成为房主。

## 7. 试玩刷新与多页保存

- 试玩刷新后手牌、世界坐标、牌序、镜头、昵称、聊天与筹码摆放继续；旧动态不重新弹出。导入 3–8 人对局后可依次切换实际席位，刷新保留正在查看的身份。
- 移动镜头后合并保存，切应用或后台时主动写入。模拟存储失败，当前桌面仍可玩但不能显示已保存；重试成功后刷新可恢复新状态。
- 两个标签页同时修改同一试玩，分别保留各自修改；过期页面另存为独立副本，原桌面不被覆盖。「其他试玩」能找回副本，切换前先保存本页。
- 复制普通试玩链接不携带本机副本编号，也不形成联机房间。不同起始牌盒的自动桌面分别保留。
- 「新开试玩」先存完整备份；备份失败则停留原桌。慢写入时重开或恢复会暂缓新动作，备份与切换之间不能插入改动。损坏的自动记录保留原件，新页面使用独立记录。重要桌面可导出文件。
- 在未保存时离页有原生提醒，保存成功后不再提醒；清空浏览器数据后明确按新试玩开始，不能误报旧记录已恢复。

## 8. 德州作为普通桌游资源

- 资源库可分别取出 52 张扑克、德州桌垫、1/5/25/100/500 面值筹码、庄家钮与规则指引。添加牌盒不会自动发筹码或启动一手牌。
- 任意玩家可抽牌、自由发放与移动筹码、传庄家钮；桌面没有下注、轮次、边池、胜负或结算限制。
- 规则指引是普通可编辑资源，正文完整显示，可复制、锁定、移动、收起和存档。
- 扑克可与其他牌盒混合成叠，来源图案保留；私人区、请求转交和牌堆操作与其他资源一致。
- 恢复旧德州完整对局或检查点，原牌序、手牌和坐标保留；原专用牌堆、牌与桌垫解除程序锁定。余额和已下注额变成普通筹码标记，原数额保留在历史中。
- 桌面物件容量已满时迁移仍保留完整筹码数额记录；新存档不再包含可执行的德州规则状态。

## 9. 本地双标签与公网

- 首次联网完成入口缓存后，停止房主服务再刷新主客页面，原投影、镜头与重连提示仍可见；恢复服务后继续原席位。联网刷新优先新入口；更新文件缺失、版本不符或缓存空间不足时保留旧完整入口。
- 离线入口仅缓存公共 HTML 与有内容版本的 JS/CSS；缓存键中没有房间、房主或个人凭据，API、SSE、私牌图片和其他来源请求不被截获。清空浏览器数据或首次未完成缓存时不保证离线刷新。
- 主客标签凭据隔离；客人投影和图片 API 不能读取别人的手牌、牌堆内容、袋内资源或个人续局口令。牌公开后可见，收回后重新隐藏。
- SSE 暂断但 HTTP 仍健康时保持桌面操作，恢复后继续接收状态与远端光标；健康检查确认离线后才暂停修改，保留最后确认视图。离线刷新保留本人的投影和镜头，恢复后重新鉴权。
- 丢失操作响应后刷新、网络恢复、房主重启都只执行一次。命令编号复用、回执过期、恢复或撤销前的未知命令要有明确提示。
- 房主关闭时访客显示不可用；旧凭据不能加入另一个新对局。玩家离席释放名额，手牌回原牌盒；清理离线不删除在线席位。
- 本地、公网以及 `--no-open` 启动均同时显示房间加入链接和房主链接；自动打开浏览器后两条链接仍在终端可见，加入链接不带 `host` 凭据。
- 公网通过 `npm run room -- --name "房主A" --pack ./game-packs/parlor-eight.json` 启动，健康检查后再分享终端房间加入链接。不同网络的两人完成抽牌、转交、拖动、装袋、合堆、聊天、自由发筹码和完整存档恢复。
- 手机熄屏、切应用再回来，与真实网络切换后重新同步；记录恢复耗时、失败提示和任何重复操作。
