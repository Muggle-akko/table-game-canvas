# Parlor 自由桌面迭代

方向：给朋友一张可以共同布置、随便玩的 2D 桌面。保留绿色桌布与实体物件感，资源库提供可以反复取用的模板，桌上物件各自独立。玩法由玩家约定。

## 原始问题

资源入口会替换整个房间；卡牌、牌背和拖动仍围绕单一中央牌堆。离线试玩维护另一套规则，新增能力容易漂移。样式积累到 5575 行，多轮覆盖相互影响。

此次界面按功能工作台处理，保留 Parlor 名称、绿色桌面和本地 Phosphor 图标。入口采用真实组件预览；世界中减少装饰和常驻说明，让操作随选择出现。

## 第一轮：卡组与统一引擎

- 重叠卡组直接整体拖动，跨区域转交保持私有投影，整组操作可一步撤销。
- 浏览器引擎由 Node 权威核心确定性生成；单机模式只保留适配层。
- 手牌、洗牌、收回、离席与重置维持权限和实例重新编号。
- 公开牌的连通组按状态建立空间索引，避免每张牌重复扫描整桌。

## 第二轮：资源实例与开放空间

- 多个牌盒并存、独立位置和牌背、按原牌盒回收。
- D6、D20、计分器、便签、收纳袋、棋盘、桌垫、棋子与筹码。
- 复制、位置锁定、编辑、移除；资源模板可以重复取用。
- 袋子只公开数量，存入卡牌重新编号，摸出卡牌进入操作者的私有手牌。
- 可放置范围从主桌扩展至 10800 × 7100；本地镜头、桌垫导航与小地图独立于同步状态。
- 桌面存档将手牌归回牌盒，保留资源、布置和计数，不保存会话、身份或聊天。

## 第三轮：界面与操作闭环

- 收拢为统一的绿色桌面、纸质资源库与紧凑工具栏，样式整理至约 630 行。
- 搜索、分类、收藏、浏览器 JSON 导入，点击添加和拖出添加使用同一条命令路径。
- 牌盒轻点选择、双击抽牌、拖动移位；拖进手牌区才抽出一张。
- 卡组优先识别袋子和手牌目标，避免开放世界范围吞掉区域操作。
- 固定手牌抽屉、物件编辑、卡牌放大、房间聊天、桌边状态、本机存档及文件导入导出。
- 手牌和牌背按资源实例渲染；未变化的卡牌 DOM 保留，减少图片重复加载。
- 命令回执带操作者可见的状态，避免 SSE 延迟时存档恢复后的导航仍使用旧布置。
- 修正锁定卡组、32 副牌容量边界、存档恢复层级、共享计数与移动端输入时侧栏被 resize 关闭的问题。

## 第四轮：取消、锁定与导入资源管理

- 锁定公共牌会阻止整组操作、一键整理和批量收回；失败操作不改变资源、历史或撤销栈，解锁后正常恢复。
- 资源库拖动在 Escape、取消、丢失指针捕获、窗口失焦和关闭面板时清理，不会因后续松手或点击再添加物件；落在其他面板或控件上不提交。
- 触屏资源预览保留原生纵向滚动和轻点添加，鼠标仍可拖出取用。
- 每次导入牌盒保存独立本机记录；同 ID 的内置包、多份导入和旧版记录均可访问，移除某份导入不影响已上桌的实例。

## 第五轮：减少常驻文案

- 移除桌面底部说明栏、顶部重复资源说明、资源库介绍、资源卡功能段落，以及物件上的双击教学文字。
- 入口保留品牌、标题、选牌与开始；物件预览直接使用组件。便签默认留白。
- 资源库在桌面和手机上均默认收起，手动点击或按 B 打开。
- 保留资源名、牌数、锁定、连接等必要状态；长说明集中到帮助，动作提示放入悬停和确认。
- 已通过 104 项自动化测试与静态构建，真实浏览器视觉验收仍待恢复工具。

## 第六轮：紧凑导航与不中断的操作（0.4.0）

- 左侧保留资源、世界、聊天、撤销、标记和工具；历史移入工具，关闭时焦点回到可见的工具按钮。
- 顶栏压缩至 58px，侧栏按内容取高，资源收藏和移除按钮在悬停或键盘聚焦时出现，触屏保持可见。
- 抽牌、翻面等常用动作直接呈现，旋转、转交和收回散牌等放入「更多」。Escape 先关闭菜单，保留选择。
- 聊天、玩家状态等无关更新保留正在打开的菜单、键盘焦点和转交对象，避免操作被打断。
- 缩放、全景和小地图集中到右下角；小地图默认关闭，支持键盘与手机按需打开，沉浸模式也可主动查看。
- 镜头取景和资源落点按实际资源库宽度避让；地图与面板操作不改变共享桌面版本。
- 已通过 107 项自动化测试、静态构建与差异格式检查。
